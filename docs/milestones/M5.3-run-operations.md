# M5.3：运行运营中心

## 完成范围

- 项目运行列表支持按多个状态、测试目标、运行环境、创建人、来源 Run、精确用例编号
  和创建时间范围组合筛选，并返回稳定的倒序分页结果；
- 可在项目范围内一次提交 1 至 100 个不重复 Run 进行批量取消。服务端先锁定并校验
  全部 Run 均属于目标项目，再在同一事务中写入状态、事件、Outbox 和审计记录；
- 任意终态 Run 可创建完整重跑；存在不可变 Result 且包含 `FAILED` 或
  `INFRA_ERROR` 用例时，可只重跑异常用例；
- 每次重跑生成新的 Run ID、创建时间、Snapshot 摘要和 Outbox 任务，同时记录
  `source_run_id` 与 `retry_mode`，形成可查询的来源血缘；
- Vue 管理端增加独立运行运营页，覆盖组合筛选、分页、指标、行选择、批量取消、完整
  重跑、仅异常重跑和血缘跳转；
- Run 详情页同步增加取消、重跑、来源提示和返回运行运营中心的入口。

## 不可变与幂等约束

- 重跑从来源 Run 已持久化的 `RunSnapshot` 构造，不读取当前环境配置、当前基线内容或
  当前自动化包；仅替换新 Run ID、创建人、创建时间，并在异常重跑时收窄用例集合；
- 仅异常重跑从来源的不可变 `RunResult` 选择 `FAILED` 与 `INFRA_ERROR` 用例。没有
  Result 或没有异常用例时返回冲突，不创建空运行；
- 重跑要求 `Idempotency-Key`。相同项目、键和请求内容返回原 Run；相同键但请求内容
  不同返回冲突；
- 批量取消对已结束或已请求取消的 Run 保持幂等，响应同时返回请求数量和实际变化
  数量；输入包含重复 ID、跨项目 ID 或不存在的 Run 时不执行部分更新；
- Project Admin 与 Tester 可执行重跑和取消，Viewer/Reviewer 仍只读；System Admin
  保持全局治理权限。

## 数据库与 API

- Alembic `20260812_0004` 为 `test_runs` 增加可空自关联 `source_run_id`、索引以及
  `retry_mode`，历史 Run 无需回填；
- `GET /api/v1/projects/{project_id}/runs` 增加 `status`、`target_id`、
  `environment_id`、`created_by`、`source_run_id`、`case_code`、`created_from` 和
  `created_to` 查询参数；
- `POST /api/v1/projects/{project_id}/runs/batch-cancel` 执行事务性批量取消；
- `POST /api/v1/runs/{run_id}/rerun` 接收 `FULL` 或 `FAILED_ONLY` 并要求幂等键；
- Run 响应增加 `source_run_id` 与 `retry_mode`，旧 Run 对应字段为 `null`。
