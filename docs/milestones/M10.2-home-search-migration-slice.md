# M10.2：首页搜索迁移切片

## 完成范围

- 从已发布 `yanjia-ai-web/case-v1.0.1` 精确选择 `TC-HOME-002`，不读取或改写旧项目运行态；
- Web Runner `0.2.0` 新增 `home-search` 模块准入，继续只支持该切片需要的 `input`、`click` 和
  `text_visible`；
- 支持“已登录成功”前置条件：每条用例在独立浏览器 Context 中通过 Run 密钥绑定登录，不复用旧项目
  `.env`、Cookie 或登录状态；
- 登录页存在门店选择器时选择首项，登录后“知道了”弹窗存在时关闭，不存在时立即继续；
- 新增通用的精确 Case Code Snapshot 构建器、当前 Runner 摘要的示例 Job，以及本地真实 Chromium
  确定性验收脚本；
- CLI 的 `validate-job` 同时执行 JSON 契约与当前 Runner 能力校验，未迁移模块失败关闭。

## 安全边界

首片选择“搜索不存在用户”，不会新增、编辑或删除业务数据，也不携带现有顾客姓名和手机号。Job 只保存
`secret://` 引用，登录账号和密码只由 Runner 进程环境或测试 Secret Provider 提供。

## 未完成范围

首页展示/跳转、顾客列表、顾客详情、影像、案例库和个人中心仍未进入 Runner 准入范围；旧 Pytest
工程不能作为任意脚本直接上传执行。后续切片应继续从已发布基线按 Case Code 选择，并为新增操作、断言和
业务数据依赖分别建立失败关闭的契约与确定性验收。
