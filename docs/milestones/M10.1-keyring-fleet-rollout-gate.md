# M10.1 多实例密钥环发布门禁

## 目标

M9.9 为单个 API 进程提供失败关闭的环境预检和稳定 `configuration_digest`，但滚动发布仍依赖运维人员逐实例执行命令、
手工收集结果并比对摘要。M10.1 增加主动的多实例发布门禁 CLI，在一次受控操作中直连全部目标 API，证明每个实例当前
就绪且加载同一份已批准 keyring 配置。

## 门禁契约

`scripts/check_supply_chain_keyring_fleet.py` 要求至少两个唯一 `NAME=ORIGIN` 实例，并读取 System Admin 短期会话 Token
文件。每个实例均绕过负载均衡访问 `GET /api/v1/admin/supply-chain/verifier-keys`，门禁结果为：

- `READY`：全部实例为 READY，且只存在一个共同配置摘要；返回 0；
- `NOT_READY`：摘要一致，但至少一个实例为 WARNING 或 BLOCKED；返回 2；
- `DRIFT`：实例摘要不一致，或共同摘要不匹配 `--expected-digest`；返回 3；
- `INVALID`：参数、Token 文件、TLS/网络、鉴权、响应大小、JSON 或响应契约错误；返回 4。

`--allow-warning` 只为有负责人和到期时间的迁移例外保留，不允许绕过 BLOCKED 或摘要漂移。`--expected-digest` 可锁定
发布审批记录中的摘要，避免所有实例同时加载一份一致但未获批准的新配置。

## 凭据与网络边界

Token 内容不允许进入命令参数、环境变量、标准输出、错误输出或报告；CLI 只从最大 4096 字节的文件读取单个无空白
Bearer Token。生产实例默认必须使用无凭据、无路径前缀、无查询参数的 HTTPS origin，可通过 `--ca-file` 加载批准的
私有 CA。重定向一律拒绝，`--allow-http` 仅允许隔离开发环境的 localhost/loopback 地址。

实例响应限制为 256 KiB。最终报告只保留实例名称、READY/WARNING/BLOCKED 状态、配置摘要、生成时间、聚合 key 数、
重叠/HMAC 状态和稳定告警代码；管理员 API 返回的 credential、工作负载身份与指纹不会复制到门禁报告。运输或解析失败
只输出失败实例名称和通用错误，不回显响应正文、内部 URL、Token 或底层异常。

## 发布流程

1. 在发布审批中记录期望镜像摘要与 keyring `configuration_digest`；
2. 为专用 System Admin 运维主体创建短期会话，把 Token 写入仅当前作业可读的临时文件；
3. 为每个 API Pod/实例准备绕过负载均衡的直连 HTTPS origin，并验证证书链；
4. 使用全部实例和 `--expected-digest` 执行 fleet CLI；
5. 仅在退出码为 0 时继续放量，随后立即吊销会话并删除 Token 文件；
6. 任一实例失败时保持发布停止，按实例修复配置注入或重启，再重新执行完整 fleet 门禁。

## 完成边界

本阶段自动化的是已经存在的管理员只读 API 与配置摘要比对，不创建长期机器 Token、不主动发现 Kubernetes Pod、不修改
实例配置，也不替代镜像摘要、UTC 时钟、真实验签流量、旧 key 拒绝、生产 Alertmanager 或真实 Kubernetes 验收。
生产编排系统仍需负责生成短期会话、解析 Pod 直连地址、限制网络出口和销毁凭据。

## 验证范围

单元测试覆盖 HTTPS/loopback 边界、实例唯一性、Token 有界读取、安全响应投影、READY/NOT_READY/DRIFT/INVALID
退出码、预期摘要锁定、迁移 WARNING 例外和重定向拒绝。运行验收在两个实际 API 容器上验证一致摘要成功，并以不同
预警策略启动负向实例证明漂移失败关闭；生产系统集成仍按完成边界保持为外部门禁。
