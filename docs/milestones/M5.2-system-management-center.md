# M5.2：系统管理中心

## 完成范围

- System Admin 可分页筛选用户，创建账号，修改显示名、系统角色和启停状态；
- 密码重置与用户禁用会立即吊销该用户全部活跃会话，且审计记录不包含密码；
- System Admin 可查看活跃或历史会话并精确吊销单个会话；接口从不返回明文 Token
  或 Token 摘要；
- 审计日志支持按项目、操作者、动作和资源类型筛选，Runner 等非用户操作者允许无
  用户名展示；
- 项目创建、名称/说明/状态更新均受 System Admin 权限保护并写入审计；
- Project Admin 可查询活跃用户候选、添加/改角/移除成员；
- 项目目标与环境支持增量更新和软归档，环境每次变更重新计算规范化配置摘要；
- Vue 管理端增加系统管理中心和项目设置页，覆盖上述用户、会话、审计、成员、目标、
  环境与 Secret 引用操作。

## 权限与安全约束

- 当前 System Admin 不能通过管理接口降级或停用自身；系统始终至少保留一名启用的
  System Admin；
- 项目始终至少保留一名 Project Admin，角色降级和成员移除使用同一服务端保护；
- Project Admin 只能查询活跃用户的 ID、用户名和显示名作为成员候选，不能访问全局
  用户状态、系统角色、会话或审计日志；
- 运行环境只保存符合契约的 `secret://` 引用。管理界面不提供明文密钥字段，审计只
  记录配置摘要和引用元数据；
- 归档采用状态字段而不是物理删除，保留 Run Snapshot、审批和审计的历史可追溯性。

## 关键 API

- `GET /api/v1/admin/users`、`PATCH /api/v1/admin/users/{user_id}`；
- `POST /api/v1/admin/users/{user_id}/password-reset`；
- `GET /api/v1/admin/sessions`、`POST /api/v1/admin/sessions/{session_id}/revoke`；
- `GET /api/v1/admin/audit-logs`；
- `PATCH /api/v1/projects/{project_id}`；
- `GET /api/v1/projects/{project_id}/member-candidates`；
- `PUT /api/v1/projects/{project_id}/members`、`DELETE .../members/{user_id}`；
- `PATCH /api/v1/projects/{project_id}/targets/{target_id}`；
- `PATCH .../targets/{target_id}/environments/{environment_id}`。

旧的 `GET /api/v1/users` 保留，以避免破坏已有客户端；新的管理列表使用独立分页响应。
